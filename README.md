# Horácio Comé

Personal portfolio for `https://horacioco.me/`.

Built as a static site with plain `HTML`, `CSS`, and a small amount of `JavaScript`.

## Main Files

- `index.html` - page structure and content
- `css/styles.css` - layout and visual styling
- `app.js` - rail navigation and small dynamic behaviors
- `og-image.png` - social preview image

## Local Preview

Open `index.html` in a browser, or serve the repo with any static file server.

## Validation

Install the dev tooling with `npm install`, then run `npm run lint` to validate the project's HTML, CSS, and JavaScript.
